`auto/docker-compose*.yml`의 경우에는 기본적으로 도커 레지스트리의 `hurwan0629/ornably-hurwan:latest` 이미지를 사용하지만 없을 경우 `ornably/Dockerfile`를 통해 빌드하여 사용하게 해놓았습니다.

모든 환경변수의 경우에는 `.env`, `.env.docker` 로 놓았으며 `ornably/auto/`의 경우에는 `.env.docker` 만으로는 일반 도커 환경변수(`${DB_PASSWORD}`, `${DB_SCHEMA}`)를 채울 수 없기 때문에 `.env`를 함께 놓았습니다.
`application.properties`에는 어디에서나 사용하게 될 고정 자원을 작성하였으며 `spring.profiles.default=`를 통해 추가로 사용할 `.properties`파일을   지정되게 하였습니다. `application-dev.properties`에는 로컬 환경에서 작업을 하게 될 때 사용할 자원들, `application-docker.properties`에는 도커를 사용할 때 넣게 될 환경자원들을 지정해주었습니다.
