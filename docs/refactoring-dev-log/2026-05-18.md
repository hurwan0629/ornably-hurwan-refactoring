### 현재 상황
배포를 위한 작업을 모두 끝낸 뒤 DB까지 정상적으로 돌아가는 도메인 깔린 배포까지 완료하였습니다.
- http://ornably.shop

### 한일들
5월 16, 17일에 걸쳐 DB개선부터 
프론트의 컴포넌트 문제 해재, 프론트 일부 더러운 주석들 정리하였습니다.

`ornably-react/` 폴더에는 배포 시 해당 리액트 프로젝트의 빌드 결과인 `dist`를 담은 nginx 이미지를 빌드하기 위한 `Dockerfile`과 `nginx.conf`를 제작해두었습니다.

`../unzip_app-war-init_sql.md`의 경우에는 AWS 콘솔에서 초기화 sql들을 풀기 위해 사용한 코드의 기록삼아 두었습니다.

최종적으로 사용한 docker-compose는 `../../docker-copose.yml`이였습니다.

이렇게 만든 배포 코드를 바탕으로 AWS의 
- Ubuntu LTS 24
- t3.small
- 30GB 저장공간
으로 서버를 받아 올리게 되었습니다.

### 후기
코드 최적화를 하던 도중 CI/CD의 자동화를 연습하기에는 먼저 CI/CD 파이프라인을 만들어 놓고 개선하는게 좋겠다는 생각이 들어 먼저 수동으로 배포를 먼저 해보았습니다.
생각보다 배포된 결과물을 보니 고쳐야할 부분이 보이긴 하지만 뿌듯한 기분이 느껴졌습니다.

이제 해제해놓았던 핸드폰 인증번호를 활성화 시키고 확인되지 않은 문제로 인해 비활성화된 카카오톡 로그인 방식을 다시 설정을 해야하며 Jenkins 등을 통해 CI/CD 자동화 파이프라인을 만들며 테스트코드, 코드 리펙토링 등등의 작업을 해나갈 예정입니다.
