### 작업 내용
이전 DB의 사용자 계정은 `root`, 비밀번호는 `1234`, 스키마는 `kevin`을 사용했습니다.
이는 애플리케이션이 관리자 권한의 DB 계정으로 접속하게 되는 문제가 있었습니다.
따라서 권한과 스키마 구조를 변경하였습니다.
[자세한 구조](../../ornably/docker/sql_structure.md)

DB의 테이블명은 대문자였지만 일부 쿼리([CartRepository의 SELECT_ALL_CART](https://github.com/hurwan0629/ornably-hurwan-refactoring/blob/main/ornably/src/main/java/bugsandwich/ornably/cart/CartRepository.java))에서는 소문자 테이블명을 사용했었습니다.
이 때문에 Linux 환경의 MySQL에서 대소문자 구분 문제에 의해 SQL 에러가 발생했습니다.

우선 사용자/스키마 문제는 `docker-compose*`와 `application*.properties`를 고치며 해결하였고, 모든 Repo와 Mapper, `*.sql`을 순회하며 쿼리를 수정하였습니다.
또한 `/ornably/docker/sql_structure.md`, `execute.md`를 통해 프로젝트 구조를 보여주는 문서를 작성하였습니다.
